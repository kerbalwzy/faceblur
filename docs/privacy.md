# 隐私设计

本产品最核心的承诺：**素材永不离开用户的设备**。这不是一句口号，而是由架构和自动化测试共同保证的。

## 为什么能做到

传统在线打码工具的数据流：

```
用户照片 → 上传服务器 → 服务器识别 → 服务器模糊 → 下载结果
                ↑ 素材副本留在服务器、日志、备份里
```

本工具的数据流：

```
用户照片 → 浏览器内存 → 本地 WASM 推理 → 本地 Canvas 模糊 → 本地生成文件
                ↑ 全程没有网络出口
```

检测模型（224 KB）和推理运行时（13.6 MB）在**首次使用时**下载，之后缓存在 IndexedDB —— 下载的是**程序**，不是用户数据。

## 三重技术保证

### 1. 没有业务后端

站点是纯静态文件。没有 API、没有数据库、没有上传接口。
`npm run build` 的产物就是 `dist/` 里的 HTML/JS/CSS/WASM/模型，扔到任何静态托管都能跑。

### 2. CSP 在浏览器层面锁死网络出口

`index.html` 中的内容安全策略：

```
connect-src 'self' blob: data:
```

这意味着**即使代码里有 bug 想外发数据，浏览器也会直接拦截**。这是第二道防线，不依赖开发者自觉。

### 3. 自动化测试强制验证

`tests/e2e/privacy.spec.ts` 用 Playwright 监听所有网络请求，断言：

| 断言 | 说明 |
|---|---|
| 图片处理全程无外部请求 | 导入 → 检测 → 导出 全链路 |
| 视频处理全程无外部请求 | 含逐帧检测与编码 |
| 无业务 API 调用 | 不请求 `/api`、`/upload` 等路径 |
| 刷新后素材不恢复 | 素材只在内存中 |
| localStorage 不含素材 | 只允许 `faceblur:prefs/locale/theme` |
| IndexedDB 只有模型缓存 | 不含任何用户数据 |
| 首屏可见隐私说明 | 不需要滚动或点开设置 |
| 页脚列明依赖许可证 | 符合商用合规要求 |

这些断言在每次 CI 中执行，任何破坏隐私承诺的改动都会让构建失败。

## 允许的「网络活动」

- 同源静态资源（页面本身、JS、WASM、模型文件）
- `blob:` / `data:` URL —— 这些是浏览器内存里的对象地址，不涉及网络传输

除此之外**没有任何请求**。

## 数据留存

| 数据 | 存放位置 | 生命周期 |
|---|---|---|
| 用户导入的图片/视频 | 浏览器内存（`ImageBitmap` / `objectURL`） | 页面关闭即释放 |
| 检测结果（人脸坐标） | Pinia store（内存） | 页面关闭即释放 |
| 导出的文件 | 用户本地磁盘（浏览器下载） | 用户自己管理 |
| 模型权重 | IndexedDB（`faceblur` 库） | 长期缓存，**不含用户数据** |
| 语言/主题/导出偏好 | localStorage | 长期，仅这 3 个键 |

## 对用户的承诺如何自证

用户不必相信文案，可以自己验证：

1. 打开浏览器开发者工具的 **Network** 面板，勾选 "Preserve log"；
2. 导入图片或视频并处理、导出；
3. 观察面板 —— **除页面自身的静态资源外，不应出现任何请求**；
4. 断网后再次导入新图片，功能依然可用（模型已缓存）。

## 已知边界

- **首次加载需要网络**：模型与运行时约 3.8 MB（gzip）。加载完成后可离线使用。
- **浏览器扩展不受 CSP 约束**：如果用户安装了恶意扩展，本产品无法阻止它读取页面内容。这与任何网页工具的限制相同。
- **截图/录屏**：用户的系统级截图工具不在防护范围内。
